# Algorithms

Quick start

- Install dev dependencies: `npm install`
- Run tests: `npm test`

Project layout

- `algorithms/` - algorithm implementations
- `DataStructures/` - data structure implementations
- `tests/` - unit tests (Vitest)
- `FP/` - A collection of pure atomic recursive functions that are commonly used to lisps (scheme, clojure...)
- `problems/` - solutions for Leetcode and AdventOfCode problems
